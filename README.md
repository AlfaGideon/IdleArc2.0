# IdleArc2.0

В репозитории пока **нет оригинального APK, исходного кода игры, протокола сервера или готового клиента**. Ссылка в Google Play ведёт на страницу приложения, а не на APK. Поэтому совместимость с официальным сервером и возможность пересборки ещё не установлены.

## Подготовка к анализу

В `tools/inspect_apk.py` находится инструмент **первичной офлайн-инвентаризации** APK. Он не устанавливает и не запускает приложение, не извлекает файлы на диск и не связывается с сервером игры. Инструмент поддерживает отдельные APK (в том числе base и split) и ZIP-контейнеры с APK, например `.apks` и `.xapk`.

В JSON-отчёте: SHA-256 входных файлов и отдельных APK, данные манифеста (пакет, версия, SDK, разрешения, компоненты), состав DEX и нативных библиотек, признаки движка и отпечатки найденных сертификатов. **Наличие сертификата не означает, что подпись APK проверена.** Имена и версии файлов, компоненты и публичные отпечатки попадут в отчёт; проверяйте отчёт перед тем, как делиться им. Инструмент не извлекает пароли, токены, строки программы или содержимое ресурсов.

### Установка и запуск

Нужны Python 3.10+ и `pip` (для установки зависимости требуется доступ к PyPI):

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt

# Один APK или все полученные от устройства split-файлы:
python tools/inspect_apk.py /path/to/base.apk /path/to/split_config.arm64_v8a.apk --output reports/inventory.json

# Либо контейнер с APK:
python tools/inspect_apk.py /path/to/game.apks --output reports/inventory.json

# Без --output отчёт выводится в стандартный вывод.
```

Не обязательно использовать именно приведённые имена split-файлов: передайте **все** APK, относящиеся к установленной версии. Если игра установлена через Google Play как набор split APK, один `base.apk` может не содержать всех библиотек и ресурсов. `.aab` не является устанавливаемым APK и этой утилитой не поддерживается.

### Как получить APK с Android-устройства

**Без компьютера:**

1. Установите [SAI (Split APKs Installer) из F-Droid](https://f-droid.org/packages/com.aefyr.sai.fdroid/). Это сторонняя утилита; её автор давно не обновлял приложение, поэтому на некоторых устройствах она может не работать.
2. Откройте SAI, раздел **Backup / Резервное копирование**, и при необходимости выберите папку для сохранения.
3. Найдите установленную **IdleArc**, выберите **Backup / Резервное копирование** и все части APK (**Backup all split APKs**, если появится такой вопрос).
4. Прикрепите сюда полученный файл `.apks` из выбранной папки. SAI сохраняет APK-файлы, а не игровые данные или OBB. Если игра дополнительно использует OBB, этот способ их не получит.

**С компьютером Windows:**

1. Установите игру на телефон. Скачайте и распакуйте официальные [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools).
2. В настройках телефона включите режим разработчика и USB-отладку. Подключите телефон кабелем и разрешите отладку в появившемся на телефоне окне.
3. Откройте PowerShell в папке `platform-tools` и проверьте подключение командой `./adb.exe devices`. Напротив устройства должно быть `device`, а не `unauthorized`.
4. Выполните блок ниже: он соберёт все пути, возвращённые Android для установленной версии, скопирует APK в новую папку и создаст рядом ZIP-архив. Если команды копирования выдали ошибку, архив не создаётся.

```powershell
$paths = @(& .\adb.exe shell pm path com.mikhaelstudio.idlearc |
    ForEach-Object { $_.Trim() } | Where-Object { $_ -like 'package:*' })
if ($paths.Count -eq 0) {
    Write-Host 'Игра не найдена или телефон не подключён.'
} else {
    $dest = Join-Path $PWD ("IdleArc_APK_" + (Get-Date -Format 'yyyyMMdd_HHmmss'))
    New-Item -ItemType Directory -Path $dest -ErrorAction Stop | Out-Null
    $failed = $false
    foreach ($line in $paths) {
        $apkPath = $line.Substring(8)
        & .\adb.exe pull $apkPath $dest
        if ($LASTEXITCODE -ne 0) {
            $failed = $true
            Write-Warning "Не удалось скопировать $line"
        }
    }
    if (-not $failed) {
        $zip = "$dest.zip"
        Compress-Archive -Path (Join-Path $dest '*.apk') -DestinationPath $zip -ErrorAction Stop
        Write-Host "Готово: $zip"
    }
}
```

Если `adb devices` показывает `unauthorized`, разблокируйте телефон и подтвердите запрос на USB-отладку. После копирования можно выключить USB-отладку. Если появится другая ошибка, сохраните её текст — но не отправляйте серийный номер устройства.

Передавайте APK только из доверенного источника. Не передавайте пароли, токены или резервные копии аккаунта. APK и каталог `reports/` исключены из Git через `.gitignore`; если сохраняете отчёт в другом месте, проверьте, что он не попадёт в репозиторий.

### Проверка инструмента

```sh
python -m unittest discover -s tests -v
```

Первичная инвентаризация не восстанавливает исходный код, игровые механики или протокол, не подтверждает подлинность APK, не проверяет работоспособность серверного API и не собирает приложение. Для глубокого анализа нужен сам APK (и все необходимые split-файлы), а для реализации — конкретное описание функций и информация о доступном серверном API.

## Важные ограничения

[Условия IdleArc, пункты 3–4](https://idlearc.com/terms), ограничивают копирование/декомпиляцию и использование модифицированных или неофициальных клиентов (кроме случаев, прямо допускаемых законом); нарушения могут привести к санкциям для аккаунта. Для работы со сторонним клиентом и официальным сервером следует уточнить разрешение разработчика и наличие официального API. Не следует обходить проверку доступа, подписи или другие защитные механизмы.

Переподписанный APK обычно нельзя установить как обновление оригинального: Android требует соответствия подписи. Кроме того, сервер может проверять подлинность клиента или требовать официальную авторизацию, поэтому успешное подключение нельзя обещать без проверки совместимости и разрешённого способа доступа.
