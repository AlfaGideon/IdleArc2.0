# Companion для IdleArc — Druid Helper (офлайн подсказчик)

**Идея:** твоя отдельная приложуха не лезет на `idlearc.com/api`, а подсказывает что качать/надеть для друида. Ты смотришь в ней, нажимаешь в основной игре сам. Это легально, без бана, и работает офлайн.

**Что уже есть из твоего APK 1.3.15 (176):**
- `companion/data/druid_skills.json` — 18 скиллов друида из `assets/flutter_assets/assets/images/classes/skills/druid/*` + строки `libapp.so`
- `companion/data/all_class_skills.txt` — 90 иконок скиллов всех классов (для сравнения билдов)
- `reports/upload-*.inventory.json` — инвентаризация APK
- Локальных цифр урона/статов в APK почти нет — баланс живет на сервере (`game_config_service.dart`). Описания скиллов в APK — только иконки и локализация, формулы надо добить из твоего опыта/скринов.

## План v1 для друида от 1 до капа

**Фаза в companion:**
1. Выбор: уровень, стиль (фарм мобов / биомы / босс), пет-стиль
2. Приоритет статов: для друида в IdleArc обычно `pet damage + Hoard/Keen Snout + Thick Pelt` для выживания, `Timberfall/Deep Roots` для пуша. Внесем твои замеры.
3. Подсказки:
   - Что качать сейчас (топ-3 скилла по уровню)
   - Какой шмот надеть (сравнение по ilvl + пет-бонусам)
   - Когда респекать через `lodgekeeper/one_soul`

**Следующие шаги:**
1. Соберем базу знаний: ты кидаешь 3-5 скринов прокачки друида (дерево скиллов, текущие статы, шмот), я заполню `companion/data/druid_builds.json`
2. Соберем APK: Flutter-проект `companion/app/` (без сети, только локальная логика). В этом окружении нет Flutter SDK, поэтому дам готовый проект + инструкцию `flutter build apk` на твоем ПК/Android Studio. Могу также сразу сделать PWA-версию которая ставится как приложение.
